# BrainCard - Progressive Web App (PWA) & Android App

BrainCard is a spaced repetition flashcard application that helps optimize long-term memory retention using adaptive review intervals.

## ✨ Features
- **PWA Ready**: Installable on Android, iOS, Windows, Mac, or Linux directly from the browser with offline support.
- **Spaced Repetition Algorithm**: Expanding review intervals (1d, 3d, 7d, 14d, 30d) based on your recall accuracy.
- **Interactive Flashcard Deck**: Tap to flip, rate your recall (Forgot / Remembered), with Web Speech API text-to-speech (TTS) pronunciation.
- **Quiz Mode**: Auto-generated multiple-choice quizzes created from your flashcard decks.
- **Heatmap Schedule**: Visual 3-week calendar view of cards due for review.
- **Folder Organization**: Categorize flashcards by subjects (General, Science, Languages, etc.).
- **CSV Import & Export**: Back up and restore your study decks anytime.
- **Dark & Light Mode**: Clean, distraction-free UI.

## 🚀 Running the PWA Locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

## 📱 Installing on Devices
- **Android (Chrome)**: Tap the 3-dot menu → **Install app** or **Add to Home screen**.
- **iPhone / iPad (Safari)**: Tap the Share button → **Add to Home Screen**.
- **Chrome / Edge Desktop**: Click the install icon in the URL bar.
